## 저장소 구조

```
2026-2-VIP3/
├── docs/          # 교과목·환경·협업·연구노트
├── docker/        # 실행 환경 (구성 예정)
├── config/        # 파라미터 (구성 예정)
├── scripts/       # 실행 진입점 (구성 예정)
└── src/           # 코드 (모듈 경계 확정 후)
```

대용량 데이터(맵 원본, bag, 가중치)는 저장소에 넣지 않고 로컬 루트 `../data/`에 둔다.
