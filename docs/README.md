## 문서 관리

- 실행 명령은 **`commands.md`**, 설정값은 **[설정 파일](../config/README.md)**이 정본이다. 패키지 README는 입출력·제약·코드 위치만 설명한다.
- 기능을 바꾸는 커밋에 실행법·인터페이스 변경도 함께 넣는다. 검증하지 않은 기능은 `예정` 또는 `미검증`으로 적는다.
- 날짜별 조사·중복 계획·옛 회의 기록은 현행 문서에 누적하지 않는다. 팀에 필요한 결론만 이 문서에 반영한다.
- 개인 논문 PDF·상세 실험·이전 문서는 저장소 밖 `../docs/`, 원본 영상·bag·설정 export는 `../data/`에 둔다. 팀 실행에 필요한 에셋은 Git에 남긴다.
- 2026-11-11 정리 이전 문서는 Git 이력으로 확인할 수 있다. 정리 당시 미커밋 내용까지 포함한 사본·이동 목록은 관리자 로컬 `docs/archive/261111-docs/`에 보존했다.
