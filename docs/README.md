## 문서 관리

- 실행 명령은 **`commands.md`**, 설정값은 **[설정 파일](../config/README.md)**이 정본이다. 패키지 README는 입출력·제약·코드 위치만 설명한다.
- 기능을 바꾸는 커밋에 실행법·인터페이스 변경도 함께 넣는다. 검증하지 않은 기능은 `예정` 또는 `미검증`으로 적는다.
- 팀 작업 이력은 **`notes/`에 유지**한다. 작업 후 노트와 목록을 갱신하고, 공통으로 바뀐 결론은 현행 계획·설계·실행법에도 반영한다. 안승현·장원태는 노트의 근거와 미해결 항목을 확인해 통합·발표에 사용한다.
- 개인 논문 PDF·상세 연구·구버전 문서 보관은 저장소 밖 `../docs/`, 원본 영상·bag·설정 export는 `../data/`에 둔다. 팀 작업 노트·작은 결과 표·대표 이미지와 실행 에셋은 Git에 남긴다. 로컬 전용 자료는 보유자와 공유 여부를 표시한다.
- 2026-11-11 정리 이전 문서는 Git 이력으로 확인할 수 있다. 로컬로 옮겨졌던 작업 노트 5개는 2026-11-12 `notes/`로 복원했다. 당시 미커밋 내용까지 포함한 원본 사본·이동 목록은 관리자 로컬 아카이브에 보존한다.
