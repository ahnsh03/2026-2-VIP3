# 알파프로젝트 교과목 개요

> 팀원이 "이 수업이 무엇을 요구하는지"를 한 번에 파악하기 위한 문서다.
> 주제·기술 내용은 다루지 않는다.

## 1. VIP란

Vertically Integrated Projects — Georgia Tech에서 시작한 **다학년·다학제 장기 연구 프로젝트**
교육 모델이다. 학기 단위로 끊기는 학습(Time), 전공 칸막이(Discipline)를 넘어 교수·대학원생·
여러 학년의 학부생이 **한 팀**으로 같은 과제를 여러 학기에 걸쳐 수행한다.

인하대에서는 미래자동차 혁신융합대학 사업단이 운영하며, **미래자동차공학 융합전공/부전공**
이수 시 알파프로젝트 1·2·3이 필수다.

| 학수번호 | 교과목 | 학점(설계) |
|---|---|---|
| FVE9001 | 알파프로젝트 1 | 1(1) |
| FVE9002 | 알파프로젝트 2 | 1(1) |
| **FVE9003** | **알파프로젝트 3** | 1(1) |

- 팀은 **3명 이상**, 다학년·다학제 구성
- 최대 (3+1)학기 동안 **동일 주제를 이어서** 연구 가능
- 교수 강의는 최소화하고 **자기주도·팀기반 학습**이 중심

## 2. 평가

일반강의는 **Pass/Fail**, 영어강의는 절대평가. 비중은 담당교수 재량이며 예시는 다음과 같다.

| 항목 | 비중(예시) |
|---|---|
| 출석 | 20% |
| 토론·발표 | 30% |
| 과제(보고서) | 30% |
| 기타(**동료평가**) | 20% |

평가도구: **연구노트**, **동료평가(필수)**, 자기평가, 중간/최종 발표, 발표 동영상·포스터, 출석.

| 도구 | 내용 |
|---|---|
| 연구노트 | 팀/개인 작업과 미팅 기록, 학습 정리, 진행 추적, 성찰·차기 계획. 후속 수강생 참조 자료로도 쓰인다 |
| 동료평가 | 참여도, 기여도, 리더십/협력 |
| 자기평가 | 자기주도 학습, 팀원 기여, 자기개발·성찰 |

연구노트는 이 저장소 [`docs/notes/`](notes/)에 작성한다. **개인 기여가 성적에 직접 반영되므로,
커밋과 연구노트 양쪽에 각자의 작업이 남도록 한다.**

## 3. 정규학기 운영 (참고 흐름)

2026-2는 정규학기이므로 아래 주차 흐름을 따른다 (담당교수 운영에 따라 달라질 수 있음).

| 주차 | 내용 |
|---|---|
| 1 | 연구과제 목표·내용 소개 |
| 2 | 팀 구성·세부 분담 |
| 3 | 세부 주제·목표 발표 |
| 4 | **관련연구 조사 발표** |
| 5 | 전문가 특강 |
| 6 | 팀별 기술 세미나·설계 |
| 7 | 전시회 / 기업탐방 |
| 8 | **중간발표·중간보고서** |
| 9–12 | 팀별 기술 세미나·설계 |
| 13 | 통합 시스템 설계·구현 |
| 14 | 성과발표회 준비 |
| 15 | **성과발표회** — 시연·포스터·최종보고서 |

> 알파프로젝트 2(하계)는 짧은 계절학기라 내부대회 준비 중심으로 운영됐다. 이번 학기는
> **정규학기 세미나·발표 중심**이므로 일정 감각이 다르다.

## 4. 학기말 산출물

| 산출물 | 비고 |
|---|---|
| 포스터 | 성과발표회 전시 |
| 기술보고서 | 최종보고서 |
| Pecha Kucha 동영상 | 표지 제외 **20장 × 20초**, 6분 이내 |

성과발표회 평가는 교수 80% + 학생 동료평가 20% (1학기 기준). 우수팀은 VIP Consortium
Innovation Competition, Global VIP Exchange 등 출전 기회가 있다.
