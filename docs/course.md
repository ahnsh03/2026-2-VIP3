# 알파프로젝트 교과목 개요

> 팀원이 "이 수업이 무엇을 요구하는지"를 한 번에 파악하기 위한 문서다.
> 출처는 2026-2 강의계획서이며, 기술 주제는 다루지 않는다.

## 1. 개설 정보

| 항목 | 내용 |
|---|---|
| 학수번호·분반 | FVE9001 **001분반** (알파 1·2·3이 같은 분반·같은 시간에 개설되어 계획서를 공유) |
| 시간·강의실 | **화 19~20교시** / 하-002 |
| 학점 | 1.0 |
| 평가 | **Pass/Fail** |
| 지도교수 | **원종훈** (전기전자공학부) — 미래형자동차 전문인력양성사업 단장, BK21 ICT-미래자동차 부단장, 스마트모빌리티공학과 학과장 겸임 · [autonav.inha.ac.kr](https://autonav.inha.ac.kr) |
| 협력업체 교원 | **(주)모라이** 자율주행·드라이빙 시뮬레이터 전문가 |

첨단분야 혁신융합대학(미래자동차) 사업과 연계한 미래자동차공학 전공 교과목이다. 전달식
강의가 아니라 **팀 프로젝트 활동을 정규 학점으로 인정**하는 모델이고, 다학년·다학제 팀이
실질적 연구과제를 수행해 학부생의 전공지식·연구능력을 기르는 것이 목적이다.

## 2. 학기 구조 — 이론 전반부 + 프로젝트 후반부

이 과목의 핵심은 **학기가 둘로 쪼개져 있다**는 점이다.

| 구간 | 주차 | 내용 |
|---|---|---|
| **이론·실무 실습** | 2~9주 | 모라이 시뮬레이터 기반 이론 강의 + 시뮬 실습. **비대면** — 주말·저녁 시간을 활용해 **강의 영상을 각자 수강**한다 |
| **중간고사** | 10주 | **이론 필기시험** — 위 강의 내용에서 출제 |
| **Term project** | 11~15주 | 팀별 설계 프로젝트 수행·점검·최종 발표 |

**실제 개발 기간은 11~15주차 약 5주뿐이다.** 그전까지는 강의 수강과 시험 대비가 병행된다.
설계 프로젝트 계획서를 11주차에 발표해야 하므로, **주제·범위·역할은 10주차 이전에 정해
둬야** 한다.

## 3. 주차별 일정

| 주차 | 내용 |
|---|---|
| 1 | 강의 소개, 드라이빙 시뮬레이터 기술 소개, **팀 확정** |
| 2 | 팀 구성·세부 연구내용 분담, 자율주행차 기술 개요, 모라이 시뮬레이터 소개 |
| 3 | ASAM 이론, ROS 이론, ROS 설치·활용 실습 |
| 4 | GPS·IMU 센서 이론 + 시뮬 실습, 정밀지도 이론 + 시뮬 실습 |
| 5 | 경로 계획 이론 + 시뮬 실습 |
| 6 | 횡/종 방향 제어 이론 + 시뮬 실습 |
| 7 | 차선·신호등 인지 기술 + 시뮬 실습 |
| 8 | 보행자·장애물 인지 기술 + 시뮬 실습 |
| 9 | 충돌 회피 기술 + 시뮬 실습 |
| **10** | **중간고사 (이론 필기시험)** |
| **11** | **설계 프로젝트 계획서 발표** — 내용·진행 방법은 교수/산업체 강사/수강생 협의하에 자율 구성 |
| 12 | 설계 프로젝트 1주차 점검 |
| 13 | 설계 프로젝트 2주차 점검 |
| 14 | 설계 프로젝트 3주차 점검 |
| **15** | **최종 발표·시연, 최종보고서 제출, 지도교수 최종 평가** |

12~14주차는 매주 진행 점검이 있다. 5주 동안 **주 단위로 보여줄 것이 있어야 한다**는 뜻이므로,
한 번에 크게 만들기보다 매주 돌아가는 것을 조금씩 늘리는 쪽이 맞다.

> 3~9주차 이론은 **자율주행** 기준(차선·신호등·보행자 인지, 충돌 회피 등)으로 짜여 있고,
> 우리 팀 주제인 자율주차와 그대로 대응하지 않는다. 중간고사는 **강의 내용 기준**이므로
> 팀 프로젝트와 별개로 준비한다. 다만 정밀지도·경로 계획·횡종 제어는 주차에도 직접 쓰인다.

## 4. 평가

| 항목 | 비중 |
|---|---|
| **중간고사** | **30%** |
| **과제(Assignment)** | **40%** |
| 출석 | 10% |
| 토론(Discussion) | 10% |
| 기타(ETC) | 10% |
| 기말고사 | 0% |

Pass/Fail로 산출된다. 기말고사는 없고 대신 **15주차 최종 발표·시연·최종보고서**가 평가
대상이다. 비중이 가장 큰 **과제 40%**가 구체적으로 무엇인지는 강의계획서에 명시돼 있지
않으므로, 실습 과제·프로젝트 산출물 중 무엇인지 **첫 공지나 교수님 안내로 확인해 갱신**한다.

## 5. 산출물

| 산출물 | 시점 |
|---|---|
| 설계 프로젝트 계획서 + 발표 | 11주차 |
| 주차별 진행 점검 | 12·13·14주차 |
| 최종 발표·시연 | 15주차 |
| 최종보고서 | 15주차 |

사업단 차원의 성과발표회(포스터, 발표 동영상)가 별도로 있을 수 있으나 이번 학기
강의계획서에는 없다. 공지되면 추가한다.

## 6. 알파프로젝트 1·2와의 차이

| | 알파 2 (2026 하계) | **알파 3 (2026-2)** |
|---|---|---|
| 학기 | 계절학기 (약 4주) | **정규학기 (15주)** |
| 운영 | 모라이 내부대회 준비·참가 중심 | **이론 강의 + 중간고사 + term project** |
| 이론 시험 | 없음 | **10주차 필기시험 30%** |
| 개발 기간 | 학기 전체 | **11~15주차 약 5주** |
| 주제 | 자율주행 | **자율주차** |

같은 분반·같은 MORAI 환경이지만 **운영 방식과 주제가 모두 다르다.** 지난 학기 감각으로
일정을 잡으면 안 된다.
