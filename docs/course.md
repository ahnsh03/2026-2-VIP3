# 알파프로젝트 교과목 개요

> 팀원이 "이 수업이 무엇을 요구하는지"를 한 번에 파악하기 위한 문서다.
> 출처는 2026-2 강의계획서이며, 기술 주제는 다루지 않는다.

실질적 연구과제를 수행해 학부생의 전공지식·연구능력을 기르는 것이 목적이다.

## 2. 학기 구조 — 강의는 녹화, 개발은 지금부터

강의계획서상 term project는 11~15주차지만, **실제 운영은 다르다.**

| 구분 | 실제 |
|---|---|
| 이론 강의 (2~9주) | **녹화 영상 자율 수강**. 정해진 시간에 묶이지 않고 부담이 크지 않다 |
| 팀 개발 | **11주차를 기다리지 않고 지금부터 팀별로 알아서 시작** |
| 10주차 중간고사 | 녹화 강의 내용에서 출제되는 **이론 필기시험**. 개발과 별개로 준비 |

즉 **강의 수강이 개발을 막지 않는다.** 대신 실제로 손을 댈 수 있는 주가 학기 전체에
흩어져 있다 (§3).

## 3. 개발 가능 주차

시험 기간과 중간고사, 최종 발표 주를 빼면 **개발에 쓸 수 있는 주는 7주**다.

| 블록 | 주차 | 성격 |
|---|---|---|
| **1블록** | **3 · 4 · 5** | 지금. 가장 긴 연속 구간 |
| — | 6 · 7 · 8 | 시험 기간 — 개발 중단 |
| **2블록** | **9** | 1주뿐. 중간고사 직전 |
| — | 10 | 중간고사 (이론 필기) |
| **3블록** | **11 · 12 · 13** | 계획서 발표와 주간 점검이 걸린 구간 |
| — | 14 · 15 | 최종 발표 준비·발표. **신규 개발 없음** |

### 여기서 나오는 것

1. **1블록(3~5주차)이 실질적으로 가장 중요하다.** 뒤로 갈수록 점검·발표가 끼어들어
   집중 개발 시간이 줄어든다. 구조를 잡고 뼈대를 돌리는 일은 여기서 끝내는 게 좋다.
2. **6~8주차에 4주짜리 공백이 생긴다** (9주차 1주를 빼면 10주차까지 사실상 단절).
   공백 전에는 **돌아가는 상태로 커밋하고 기록을 남긴다.** 반쯤 고친 채로 두면 복귀 비용이
   그 자체로 한 주다.
3. **9주차는 1주뿐**이다. 큰 작업을 시작하지 말고, 공백에서 복귀하며 상태를 되살리고
   11주차 계획서에 쓸 내용을 정리하는 데 쓴다.
4. **13주차가 사실상 마지막 개발 주**다. 14~15주차는 발표·시연·보고서이므로
   **13주차 말에 기능을 동결**하고 그 뒤로는 안정화와 자료 준비만 한다.

각 블록 마지막 주에는 [작업 기록](notes/)을 반드시 남긴다.

## 4. 강의계획서 주차별 일정

| 주차 | 내용 |
|---|---|
| 1 | 강의 소개, 드라이빙 시뮬레이터 기술 소개, **팀 확정** |
| 2 | 팀 구성·세부 연구내용 분담, 자율주행차 기술 개요, 모라이 시뮬레이터 소개 |
| 3 | ASAM 이론, ROS 이론, ROS 설치·활용 실습 |
| 4 | GPS·IMU 센서 이론 + 시뮬 실습, 정밀지도 이론 + 시뮬 실습 |
| 5 | 경로 계획 이론 + 시뮬 실습 |
| 6 | 횡/종 방향 제어 이론 + 시뮬 실습 |
| 7 | 차선·신호등 인지 기술 + 시뮬 실습 |
| 8 | 보행자·장애물 인지 기술 + 시뮬 실습 |
| 9 | 충돌 회피 기술 + 시뮬 실습 |
| **10** | **중간고사 (이론 필기시험)** |
| **11** | **설계 프로젝트 계획서 발표** — 내용·진행 방법은 교수/산업체 강사/수강생 협의하에 자율 구성 |
| 12 | 설계 프로젝트 1주차 점검 |
| 13 | 설계 프로젝트 2주차 점검 |
| 14 | 설계 프로젝트 3주차 점검 |
| **15** | **최종 발표·시연, 최종보고서 제출, 지도교수 최종 평가** |

12~14주차는 매주 진행 점검이 있다. **주 단위로 보여줄 것이 있어야 한다**는 뜻이므로, 한 번에
크게 만들기보다 매주 돌아가는 것을 조금씩 늘리는 쪽이 맞다.

11주차 계획서 발표 시점에는 이미 1·2블록(3~5, 9주차)의 결과물이 있다. 따라서 계획서는
백지에서 세우는 계획이 아니라 **지금까지 만든 것 + 남은 3주(11~13) 계획**이 된다.

> 3~9주차 이론은 **자율주행** 기준(차선·신호등·보행자 인지, 충돌 회피 등)으로 짜여 있고,
> 우리 팀 주제인 자율주차와 그대로 대응하지 않는다. 중간고사는 **강의 내용 기준**이므로
> 팀 프로젝트와 별개로 준비한다. 다만 정밀지도·경로 계획·횡종 제어는 주차에도 직접 쓰인다.

## 5. 평가

| 항목 | 비중 |
|---|---|
| **중간고사** | **30%** |
| **과제(Assignment)** | **40%** |
| 출석 | 10% |
| 토론(Discussion) | 10% |
| 기타(ETC) | 10% |
| 기말고사 | 0% |

Pass/Fail로 산출된다. 기말고사는 없고 대신 **15주차 최종 발표·시연·최종보고서**가 평가
대상이다. 중간고사 30%는 녹화 강의 내용에서 나오므로 팀 개발과 별도로 챙긴다. 비중이 가장 큰 **과제 40%**가 구체적으로 무엇인지는 강의계획서에 명시돼 있지
않으므로, 실습 과제·프로젝트 산출물 중 무엇인지 **첫 공지나 교수님 안내로 확인해 갱신**한다.

사업단 차원의 성과발표회(포스터, 발표 동영상)가 별도로 있을 수 있으나 이번 학기
강의계획서에는 없다. 공지되면 추가한다.

## 7. 알파프로젝트 1·2와의 차이

| | 알파 2 (2026 하계) | **알파 3 (2026-2)** |
|---|---|---|
| 학기 | 계절학기 (약 4주) | **정규학기 (15주)** |
| 운영 | 모라이 내부대회 준비·참가 중심 | **이론 강의 + 중간고사 + term project** |
| 이론 시험 | 없음 | **10주차 필기시험 30%** |
| 개발 기간 | 학기 전체 (약 4주 집중) | **3·4·5 / 9 / 11·12·13 — 흩어진 7주** |
| 주제 | 자율주행 | **자율주차** |

같은 분반·같은 MORAI 환경이지만 **운영 방식과 주제가 모두 다르다.** 지난 학기 감각으로
일정을 잡으면 안 된다.
