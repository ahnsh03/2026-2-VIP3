밀리지 않게 쓴다.

## 규칙

| 항목 | 기준 |
|---|---|
| 파일 이름 | `주차-이름.md` — 예: `w03-seunghyun.md` |
| 주기 | **매주 1개**, 각자 작성 |
| 분량 | 길 필요 없다. 무엇을 했고 다음에 뭘 할지가 남으면 된다 |
| 팀 미팅 | 그 주 담당자가 `w03-meeting.md`로 따로 남긴다 |

[TEMPLATE.md](TEMPLATE.md)를 복사해서 쓴다.

## 왜 저장소에 두나

- 커밋 히스토리와 함께 보면 **누가 무엇을 했는지**가 그대로 증거가 된다
- 중간보고서·최종보고서·포스터를 쓸 때 재료가 된다
- 교과목 취지상 **후속 수강생이 참조할 기록**이기도 하다

개인 정보, 계정, 라이선스 키는 적지 않는다.
