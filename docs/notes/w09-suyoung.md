- Transformer-Based Parking Slot Detection Using Fixed Anchor Points (2023)

| 항목 | Fixed Anchor Transformer |
|---|---|
| **입력 형태** | 차량 주변 카메라로 만든 AVM 이미지 |
| **출력 표현** | 고정 앵커를 이용해 주차칸을 구성하는 두 기준점을 검출하고 슬롯 위치를 추론 |
| **사전학습 가중치** | 논문에서 공개 사전학습 가중치 제공 여부를 확인하지 못함. 코드·가중치 공개 여부를 저장소에서 추가 확인할 필요가 있음 |
| **학습 데이터** | SNU 주차 슬롯 데이터셋에서 평가. 적용 시 동일 형식의 주차칸 기준점 라벨 필요 |
| **모델 크기** | 논문에 프로젝트 GPU 조건에서의 학습 메모리·추론 속도 정보가 명시되어 있지 않아 직접 확인 필요 |
| **프로젝트 적합도** | 두 기준점으로 슬롯 위치를 표현하므로 좌표를 반환하는 목적에 적합한 대안. 실제 카메라 시점과 라벨 형식의 호환성 확인 필요 |
| **슬롯 검출 정확도 SNU** | precision **96.61%**, recall **96.11%** (논문 보고값) |
| **주의사항** | 논문 수치는 SNU 데이터셋 기준이며 PS2.0에서 DMPR-PS와 직접 비교한 수치가 아님 |

출처: [논문 (IEEE Access, 2023)](https://doi.org/10.1109/ACCESS.2023.3315738)

- **Attentional GNN (주차칸 표식점 그래프 모델, 2021)**

| 항목 | Attentional GNN |
|---|---|
| **입력 형태** | 차량 주변 카메라로 만든 AVM 이미지 |
| **출력 표현** | 주차선 표식점을 검출한 뒤 그래프 신경망으로 점 사이의 연결 관계를 학습해 슬롯을 구성 |
| **사전학습 가중치** | 연구 코드 공개: [GitHub 저장소](https://github.com/Jiaolong/gcn-parking-slot). 사전학습 가중치 제공 여부는 저장소에서 별도 확인 필요 |
| **학습 데이터** | PS2.0 및 PSV 데이터에서 실험. 표식점 좌표와 입구선 정보를 라벨로 사용 |
| **모델 크기** | ResNet18 백본 기준 논문 실험에서 16.2 ms/이미지, ResNet50은 21.4 ms/이미지 (GTX 1080 Ti). 프로젝트 GPU 성능과는 다를 수 있음 |
| **프로젝트 적합도** | 표식점 간 관계를 직접 학습하므로 슬롯 좌표를 추론하는 목적에 적용 가능. 주변 시야 영상 외의 CCTV·사선 영상은 별도 검증 필요 |
| **슬롯 검출 정확도 PS2.0** | 논문 기본 설정에서 precision **99.56%**, recall **99.42%** |
| **주의사항** | 가려져 표식점이 보이지 않는 경우 실패할 수 있음. 논문 정확도는 해당 데이터셋 및 실험 설정 기준 |

출처: [논문 (arXiv:2104.02576)](https://arxiv.org/abs/2104.02576) · [코드 저장소](https://github.com/Jiaolong/gcn-parking-slot)

- Mask R-CNN 기반 주차 슬롯 검출 (2020)

| 항목 | Mask R-CNN |
|---|---|
| **입력 형태** | 일반 카메라 영상 또는 AVM 이미지 1장 |
| **출력 표현** | 주차선 표식점·영역의 객체 위치와 픽셀 단위 분할 마스크 |
| **사전학습 가중치** | COCO 등 일반 객체용 가중치는 제공되는 구현이 있으나 주차칸 전용 가중치는 별도 확인 필요 |
| **학습 데이터** | 주차 표식의 객체 라벨과 마스크 라벨 필요. 현재 점 라벨만 있다면 마스크를 추가로 만들어야 함 |
| **모델 크기** | 분할 헤드까지 포함하므로 경량 검출 모델보다 연산량이 클 수 있음. 프로젝트 장치에서 직접 측정 필요 |
| **프로젝트 적합도** | 주차선 표식의 형태와 경계까지 얻을 수 있는 후보. 슬롯 좌표는 분할 결과를 후처리해 계산해야 함 |
| **슬롯 검출 정확도 PS2.0** | 논문에서 동일 기준의 PS2.0 슬롯 precision·recall 수치를 확인하지 못함 |
| **주의사항** | 픽셀 마스크 라벨링 비용이 크며, 분할 마스크가 곧 슬롯 좌표를 의미하지는 않음 |

출처: [논문 (Applied Sciences, 2020)](https://www.mdpi.com/2076-3417/10/12/4295)

**## 팀 공유 사항**

다른 사람이 알아야 할 결정, 인터페이스 변경, 요청 사항.

- **대안 모델 후보** => **Fixed Anchor Transformer, Attentional GNN**
- Fixed Anchor Transformer는 두 기준점 좌표로 슬롯을 표현하므로, 슬롯 위치를 반환하는 인터페이스와 잘 맞음
- Attentional GNN은 표식점의 연결 관계를 학습해 슬롯을 구성하며, 공개 코드가 있어 구현을 검토할 수 있음
- Mask R-CNN과 주차선 의미 분할은 픽셀 경계 정보를 얻을 수 있지만, 마스크 라벨과 슬롯 좌표 변환 과정이 추가로 필요함
- 보고된 정확도는 각 논문의 데이터셋·설정에 한정됨.
