# 개발 계획

## 목표와 범위

MORAI **K-City 2025 / 2023_Hyundai_Ioniq5**에서 직접 구성한 센서로 주차칸을 인식하고, 선택한 일반 주차칸 하나에 저속 전방주차한다. GT로 먼저 제어를 개발하되 최종 인지 시연의 목표는 센서 출력으로 만든다. 후방·평행주차는 전방주차가 안정적으로 끝난 뒤의 확장이다.

팀원 5명 × 주 3시간 × 5주 = **75인시**이며, 주 개발자 3명의 구현 시간은 **45인시**다. 관리·발표 담당 2명의 시간을 별도 모듈 개발이나 대량 라벨링 시간으로 계산하지 않는다. 수업 요구는 논문 전체 재현보다 **핵심 모듈 적용과 비교 실험**이다.

## 현재 상태

| 구분 | 2026-11-12 상태 | 다음 완료 기준 |
|---|---|---|
| 연결·센서 | 9090 실제 수신 확인: 4어안 약 10Hz·1280×960, Ego 약 44.5Hz(설정 50Hz) | 다른 팀 PC에서도 동일 프리셋·명령으로 수신 확인 |
| SVM | `vip3_perception`: 렌즈·지면 보정 프로필, 자세·시차 보상, 512×512 진단 출력·CPU 최적화 구현 | 다른 위치·후방–좌측 겹침·주행/경사 검증, clean BEV 출력 |
| 데이터 | raw bag 수집·감사·재생 도구 구현, 주차 GT 31개 제공 | 같은 짧은 bag을 세 개발자가 재생, 학습용 clean BEV export |
| 인지 | SS-PSD 외부 소스 확보 | 공개 가중치 추론, ROS 출력·직접 라벨·소규모 학습은 남음 |
| 경로·제어 | `vip3_parking`에 상태·기어·GT·평가 통합 | GT 목표 pose 어댑터·경로 생성·추종·종료 로직 구현 |

6개 패키지 구조와 검증 범위는 [src 문서](src-refactoring.md), 실제 측정·인수인계는 [11/12 통합 노트](../notes/261112-integration.md)에 있다. 검사 통과를 SS-PSD·자율주차 완료로 해석하지 않는다.

## 5주 진행안

아래 날짜는 기존 팀 일정 기록을 바탕으로 한 작업 배치다. **11/17 중간발표, 12/06 기능 동결, 12/15 최종발표**를 유지하고, 5주차는 신규 기능보다 재현·평가에 쓴다. 수업 공지가 바뀌면 이 표 한 곳을 갱신한다.

| 주차 | 날짜 | 핵심 산출물 | 통과 기준 |
|---|---|---|---|
| 1 | 11/09–11/15 | 연결 재현, 공통 bag, GT 목표 정의, 공개 모델 첫 추론 | 세 파트가 같은 입력으로 각자 실행; 주차칸 ID·진입 방향·시작 자세 기록 |
| 2 | 11/16–11/22 | SVM 정합·clean BEV, GT 전방주차 1회, 소량 라벨 규칙 | 차체 바로 옆 선·뷰 경계 확인; 목표가 후륜축 pose인지 대조 |
| 3 | 11/23–11/29 | SS-PSD 인지 좌표 출력, 고정 평가 세트, 최소 추가 학습 | 공개 가중치 결과를 먼저 저장; 학습 전후를 동일 데이터로 비교 |
| 4 | 11/30–12/06 | 인지 목표와 제어 통합, 실패 처리, 기능 동결 | 인지 실패 때 정지; 재현 가능한 전방주차와 GT/인지 비교 로그 |
| 5 | 12/07–12/13 | 반복 평가, 영상·표·발표 자료 | 고정 시작 조건별 성공·실패 전부 기록; 실행법을 새 터미널에서 재현 |

매주 개인 3시간은 대략 공통 상태 확인 15분, 자기 파트 구현·실험 2시간, 검증·인수인계 45분으로 쓴다. 작업 종료 때 [노트](../notes/README.md)를 작성하고, 다음 공통 확인 때 안승현·장원태가 결과·막힌 점·발표 근거를 검토한다. 시작 조건을 늘리기보다 한 조건을 끝까지 연결한다.

## 완료 기준과 일정이 부족할 때

- 최종 시연: 센서로 목표를 만들고 지정 칸에 전방주차, 충돌 없음, 차량 외곽이 칸 안에 들어감. 유효한 인지가 없으면 정지하며 GT 목표로 몰래 전환하지 않는다.
- 평가: 가능한 범위에서 같은 시작 조건으로 GT 목표와 인지 목표를 각각 반복하고, 공개 가중치와 추가 학습 결과를 같은 홀드아웃 run으로 비교한다. 회수·실패 사유를 함께 공개한다.
- 입력 부족·지연·목표 유효성·단일 제어 발행자 확인 후 통합한다. 고정 조건 5회 반복을 우선 목표로 삼되 성공한 회차만 고르지 않는다.
- 부족하면 역주차·평행주차·DMPR-PS 추가 비교·반지도 전체 학습 순으로 제외한다. 인지가 부족하면 **GT 제어 시연 + 분리된 인지 평가**로 결과를 정확히 설명하고 센서 기반 통합 완료로 보고하지 않는다.

실험 방법은 [데이터와 평가](../system/data.md), 담당 경계는 [역할과 오너십](team.md)을 따른다.
